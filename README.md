Suite of Matlab scripts to help organize and analyze ERG flash data. 

Starts with .mdb files then converts them to .json via dbeaver. From there uses Matlab for organization/analysis/plotting.

See the PDF readme for instructions.

Use your UofL login to download Matlab here: https://www.mathworks.com/academia/tah-portal/university-of-louisville-31448597.html
  - Be sure to select every toolbox when prompted during installation
